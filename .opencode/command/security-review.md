نفّذ مراجعة الأمان الكاملة لتطبيق Air Menu Projects واعطِ قراراً نهائياً (موافق/مرفوض) للنشر:

- [ ] `git ls-files | grep -E "^\.env$"` يجب أن يكون فارغاً (لا أسرار في git).
- [ ] لا مفاتيح/توكنات/كلمات سر مكتوبة داخل الكود.
- [ ] `APP_DEBUG=false` و`APP_ENV=production` في الإنتاج.
- [ ] صلاحيات `storage/` و`bootstrap/cache/` = 775.
- [ ] مدخلات المستخدم مُعقّمة (لا SQL injection / XSS).
- [ ] الاختبارات اجتازت (تأكيد من الثعلب).
- [ ] توجد نسخة احتياطية حديثة في `~/_archive/`.

اختم بقرار واضح: **APPROVED للنشر** أو **REJECTED مع الأسباب**.
