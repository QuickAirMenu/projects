# رسائل الوكلاء — دليل الجلسات

## ترتيب التشغيل لكل ميزة جديدة

```
┌─────────────────────────────────────────────────────┐
│  1️⃣  التنين  →  يخطّط ويقسّم                         │
│       ↓                                             │
│  2️⃣  الأسد + النمر  (بالتوازي حسب الحاجة)           │
│       ↓                                             │
│  3️⃣  الفهد  (إصلاحات سريعة أثناء البناء)            │
│       ↓                                             │
│  4️⃣  الذئب  (لو فيه مهام طويلة/هجرات)              │
│       ↓                                             │
│  5️⃣  الثعلب  →  اختبار                              │
│       ↓                                             │
│  6️⃣  السلحفاة  →  مراجعة أمان  ← يجب قبل النشر     │
│       ↓                                             │
│  7️⃣  النسر  →  النشر على السيرفر                    │
└─────────────────────────────────────────────────────┘
```

### من يعمل بالتوازي؟
- **الأسد + الذئب**: لو الميزة تحتاج بناء كود ضخم وهجرة بيانات معاً.
- **الثعلب + الفهد**: لو الثعلب يختبر والفهد يصلح أخطاء صغيرة بالتوازي.
- **السلحفاة**: دائماً **وحدها** — لا يبدأ النسر قبل انتهائها.

---

## كيف تستخدم هذا الملف

1. افتح جلسة opencode جديدة.
2. اختر الوكيل المطلوب بكتابة `@اسم-الوكيل` في أول رسالة.
3. انسخ الرسالة المقابلة أدناه (استبدل `[وصف المهمة]` بمهمتك الفعلية).
4. الصقها وأرسل.
